# 企业 OA 智能采购与制度问答助手：交付说明

| 功能 | 实现 | 验收记录 |
|---|---|---|
| 制度问答 | 按条款切分、向量检索、逐项引用、证据复核、拒答与追问 | 待填写真实运行结果 |

## 架构

浏览器 → Nginx（TLS、演示账号、限速、静态演示页）→ assistant（意图路由、参数校验、RAG）→ OA（SQLite与审批规则）。
模型调用使用外部API；模型不直接连接数据库、不决定审批阈值、不执行任意Python或用户提供的URL。

## 数据说明

- 制度为个人项目模拟资料，不代表真实企业规定。
- 实际制度数、条款数：以check_runtime输出为准。
- OA种子月份为2026-10。云端OA命名卷与本机数据库互相独立。
- 预算未找到、余额为零、OA故障分别表达。

## 测试说明

- 离线单元测试：检验流程、参数与异常分支，不代表模型准确率。
- 检索Top-1/Top-5：只衡量开发集检索命中，不代表最终答案正确。
- 云端验收：网关检查与17道真实问题；逐题人工检查答案和引用。
- 记录：Git提交、运行时间、模型名、资料指纹、镜像摘要、通过数和失败原因。不要写未经测得的准确率、并发量或响应时延。

## 主要限制

- 单轮、单动作；收到追问后需重新提交完整问题。
- 仅支持模拟人民币采购规则，不自动换汇，不写入审批、不扣预算。
- Basic Auth是演示入口访问控制，不是企业账号权限系统。
- 复核模型仍可能判断错误；真实引用也可能不足以支持结论。
- 当前只允许条款正文作为引文。只存在于scope元数据/前言的适用范围仍可能无法回答；应单独记录此边界，不用错误的测试夹具证明它已解决。

## 3分钟演示脚本

1. 展示HTTPS与登录。
2. 问“采购8000元需要谁审批”，查看工具参数、审批链和rule_version。
3. 问“查询研发部2026-10预算”，查看预算来源。
4. 问拆单制度，查看条款引用。
5. 省略部门或币种，展示追问；问知识库之外的问题，展示拒答。
6. 展示已记录的端口/网络排障与恢复过程。
